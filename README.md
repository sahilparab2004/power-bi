# Power BI Project – Olympics Data Analysis

## 📌 Project Overview
This project is a **Power BI dashboard** created to analyze and visualize **Olympics data**.
The main goal of this project is to transform raw data into meaningful insights using
interactive dashboards and KPIs.

This project demonstrates my skills in:
- Data cleaning
- Data modeling
- Data analysis
- Data visualization using Power BI

---

## 🧠 Problem Statement
Raw Olympics data is large and difficult to understand in tabular form.
The objective of this project is to:
- Analyze Olympics performance data
- Identify trends and patterns
- Present insights in a clear and interactive dashboard

---

## 📊 Dataset Information
- Dataset contains Olympics-related data such as:
  - Countries
  - Athletes
  - Sports
  - Medals (Gold, Silver, Bronze)
  - Year-wise performance
- The data was imported directly into **Power BI Desktop**

---

## ⚙️ Tools & Technologies Used
- **Power BI Desktop**
- **Power Query Editor** (for data cleaning)
- **DAX (Data Analysis Expressions)** for calculations
- **Data Modeling** (relationships between tables)
- **GitHub** (for project sharing)

---

## 🛠️ How I Built This Project (Step-by-Step)

### 1️⃣ Data Import
- Imported the Olympics dataset into Power BI Desktop
- Verified data types and structure

### 2️⃣ Data Cleaning (Power Query)
- Removed unnecessary columns
- Handled missing and null values
- Renamed columns for better readability
- Ensured correct data types (text, numbers, dates)

### 3️⃣ Data Modeling
- Created relationships between tables (if multiple tables were used)
- Ensured proper cardinality (One-to-Many)
- Optimized the model for performance

### 4️⃣ DAX Calculations
Created measures using DAX such as:
- Total Medals
- Gold Medals Count
- Silver Medals Count
- Bronze Medals Count
- Country-wise Medal Count
- Year-wise Performance

### 5️⃣ Dashboard Creation
- Designed interactive visuals such as:
  - Bar charts
  - Line charts
  - Pie charts
  - Tables
  - Cards (KPIs)
- Added slicers for:
  - Year
  - Country
  - Sport
- Applied consistent color theme and layout
